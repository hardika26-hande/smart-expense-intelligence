# Smart Expense Intelligence

## Project Overview

This project is an interactive expense-tracking and spending-analysis dashboard built using Python and Streamlit.

It helps users analyze spending habits, understand expense patterns, and gain insights through interactive visualizations.

## Dataset

The project uses expense data containing transaction dates, categories, amounts, and payment modes.

## Technologies Used

- Python
- Pandas
- Plotly
- Streamlit

## Key Features

- Expense data preprocessing
- Category-wise spending analysis
- Monthly spending trend visualization
- Interactive filters for categories and payment modes
- Spending summary metrics
- Interactive Streamlit dashboard
